## Remaining blockers / follow-ups
1. **Live verification** — runs automatically on the first push (`verify-streams.yml` triggers on changes to
   `data/approved/`) and daily afterwards.
2. **Evidence confirmation** — a maintainer should open each `source.evidence_url`, confirm free availability, and set
   `source.evidence_checked`. Records whose evidence cannot be confirmed should move to `data/pending/`.
3. **Enable GitHub Pages** (Settings → Pages → Source: GitHub Actions) — the workflow token cannot do this itself.
